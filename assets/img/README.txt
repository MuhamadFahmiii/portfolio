FOLDER UNTUK FOTO / SCREENSHOT PROYEK
======================================

Simpan foto proyek di folder ini dengan nama berikut:

1. project-trafoindo.jpg   -> screenshot website company profile Trafoindo
   (untuk kartu "Company Profile & CMS" di section Projects)

2. project-sentiment.jpg   -> screenshot/visualisasi proyek analisis sentimen
   (untuk kartu "Sentiment Analysis with IndoBERT" di section Projects)

Tips:
- Format JPG/PNG/WebP, disarankan rasio landscape (mis. 1600x1000 px)
  karena foto akan dipotong otomatis (object-fit: cover) ke tinggi 200px
- Selama file belum ada, website otomatis menampilkan banner gradient
  dengan ikon — jadi tidak ada gambar rusak

Mengganti nama file lain? Sesuaikan src pada index.html:
  <img class="project-img" src="assets/img/project-trafoindo.jpg" ... />
